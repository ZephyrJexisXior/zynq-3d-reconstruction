# GitHub 上传说明

1. 解压压缩包，进入 `fpga-modeling-workbench` 文件夹。
2. 将该文件夹内的文件作为仓库根目录内容上传，包括隐藏文件 `.gitignore`。上传源码文件能在 GitHub 直接浏览和比较修改；仅上传 ZIP 则只是保存一个附件。
3. 保留 `README.md`、`requirements*.txt`、`config/default.json`、`licenses/` 和上游声明，不必另传权重或 Python 环境。
4. 不要把原电脑工程的 `data/`、`models/`、`runtime*/`、`config/local.json`、照片和生成模型再复制进仓库。权重由下载脚本另行获取。

本包来自2026年11月3日当前代码，包含前景完整性修正、灰彩分步、照片贴图和进度页面。源码未执行联网发布，也没有创建 GitHub 仓库。

`source_manifest.json` 记录本包每个文件的字节数与 SHA-256，可用来验证传输完整性。`docs/本机使用与历史记录.md` 是历史记录，安装启动以仓库根目录 README 为准。

许可证按各组件原文件保留；源码包不附带自拟的全项目 MIT 授权。运行需要另外安装依赖、下载权重并配置设备参数。
