# 硬件与处理职责

- 开发板：启明星Zynq-7020，OV5640接DVP主摄接口，顶部UVC摄像头接USB Host。
- 云台：原连续旋转舵机，黄线V7，独立5V供电并共地；KEY0为PL按键（L14）。
- 结构：开发板固定平台、物体转台、周边挡板和稳定柔光；相机和灯在一轮中保持固定。
- FPGA PL：帧时序/完整性、YCoCg/降噪/轻锐化/暗部处理、质量统计、候选局部特征与匹配。
- ARM PS：初始化与USB Host、间隔调度、静止取帧、DDR回放、清单、无损保存和网络。
- 电脑：主体分割及边缘修正、SuperPoint/LightGlue/COLMAP配准、四视图Hunyuan形状、
  UV与照片贴图、缺色插值、预览和导出。AI几何与补色中包含推断成分。

本工程V7=1612µs运动、1500µs停止，580ms×18；这些数值只适用于已验证实物。
相同PWM不保证不同负载和电压下相同转角。自动对焦需要可调焦硬件，图像锐化不能替代光学对焦。
高清参数须检查完整输出，不能仅以分辨率设置值宣称500万有效照片。
